# 迁移前契约参考

此目录冻结 main 的 dee9fe4 状态机协议及最小存储适配器，仅供原有契约测试和迁移差异对照。生产代码禁止导入本目录，构建也不包含这里。

这些测试通过只代表旧契约仍可用于对照，不能作为 LangGraph 运行时验收。新实现由 integration/langgraph-native、审核 API、mini-workflow、DAG 与浏览器回归直接验收。保留参考是为了不丢弃原有测试资产，今后可随对应契约迁移逐项缩减。

这里冻结的是原状态机协议和最小适配器，公共业务模块（例如当前 IssueTracker 和 IssueRunStore）仍使用现有实现。因此它是行为契约对照，不是旧版应用的完整可执行快照。需要运行完整旧版应用时，请使用原 main 或保留的实验工作树。
