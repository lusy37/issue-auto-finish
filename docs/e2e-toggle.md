# 浏览器验收开关

main 与 LangGraph Native 两个独立实现均支持全局 E2E 开关，默认开启。设置页取消“启用浏览器验收（E2E）”，或在实例配置中设置 `E2E_UI_ENABLED=false`，保存后重启服务。

| 配置 | 流程 | 交付要求 |
| --- | --- | --- |
| 开启 | plan → review → build → verify → uat → 交付 | verify 通过，并取得本次 Playwright 退出码和有效报告 |
| 关闭 | plan → review → build → verify → 交付 | verify 通过，明确注明“浏览器验收未启用” |

关闭只省略浏览器验收及其配置生成，不增加替代验收。代码验证保留 lint、构建、关联测试与计划完成检查；验证失败仍按原配置处理自动修复。预览服务由预览配置独立控制。

任务初始化时保存本轮阶段列表，是否包含 uat 就是本轮 E2E 要求，不再额外保存同义布尔字段。新任务和完整重做读取当前全局配置；暂停继续、审核恢复、服务重启及普通重试均保留本轮阶段列表。不提供单 Issue 开关，也不自动迁移旧数据。

main 和 Native 的交付仍核对当前候选提交的 verify 凭证、全部内部任务合并状态与 Git 工作区；开启 E2E 时还需同一候选提交的 UAT 凭证。Native 在 verify 通过后按本轮要求选择 uat 或 deliver，保留 UAT 节点供原流程恢复。

自动回归覆盖配置保存、非法值拒绝、任务恢复与完整重做、关闭后的交付，以及开启时拒绝缺失 UAT 凭证。新增完整流程测试使用无 Playwright 配置的仓库，经过计划审核、重建服务和 tracker、代码验证以及真实本地 Git 推送；AI 和 GitHub 使用模拟响应，不代表重新完成真实 Codex/GitHub 验收。
