已通过旧实例的 instance.lock、PID 启动时间和 tracker 中的确切冲突路径确认身份，随后仅停止该实例。核验时发现 153 条指向 mini 的重复失败评论，评论与原始冲突记录均保留。依据新工程真实 completed 状态、有效 UAT 和既有 PR 回写，验收代理恢复被覆盖的完成标签；停止后再次读取 GitHub 确认标签稳定。

路径解析按各自工程根目录或显式环境配置工作。当前 instance.lock 位于各自 DATA_DIR 内，只保证同一数据目录单实例；不同数据目录没有共享仓库锁。因此这是两个实例消费同一个远程 Issue 的冲突，现有数据目录锁不能防止这种运行方式。以后对该沙箱执行验收时，先停止其他监听同一仓库的工作台，仅启动所需工程实例。本次未改为跨目录或跨机器调度。
